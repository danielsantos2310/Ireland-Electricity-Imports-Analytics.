# Design direction — Project 04 · Generation & Import Exposure

## Series identity
Project 04 of the Daniel Santos Infrastructure Analytics Series. Shared navigation and evidence language make the five sites feel like one professional research product family.

## Audience
Recruiters, data/energy professionals and infrastructure practitioners. Support a fast executive scan plus a deep evidence review.

## Single job
Explain how Ireland’s generation mix changed and which external fuel/import dependencies remain.

## Visual system
Background `#07131C` · surface `#0D1E29` · text `#F4F8FA` · muted `#9AB0BA` · project accent `#7ED8A4` · gas/cost amber `#F3B45D` · imports cyan `#69D8E7` · risk coral `#F27668`.

## Signature
A system-balance visual that treats renewables, gas, imports and storage as interacting infrastructure rather than isolated technologies.

## Information architecture
Question → Evidence → Analysis → Finding → Limitations → Sources → Next project.

## Interaction contract
Core narrative remains readable without JavaScript. Canvas charts redraw responsively. Keyboard focus stays visible. Motion respects `prefers-reduced-motion`. Mobile preserves reading order and avoids page-level horizontal scrolling.
